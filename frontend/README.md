# Frontend - SETEC Solar

Para a documentação completa de execução, variáveis de ambiente, perfis de acesso e arquitetura, consulte o [README principal do projeto](../README.md).

### Scripts Disponíveis:
* `npm run dev`: Inicia o servidor de desenvolvimento Vite em `http://localhost:5173`
* `npm run build`: Compila TypeScript e gera o bundle de produção em `dist/`
* `npm run lint`: Executa verificação do ESLint
